---
title: Mirror tests in a tests/ directory beside src/
description: Keep tests beside the production tree, with matching paths and a separate TypeScript project.
sidebar:
  label: Test layout
---

Each workspace keeps tests in `tests/`, mirroring the paths under `src/`:

```text
workers/processor/
  src/artifacts/profile-csv.ts
  tests/artifacts/profile-csv.test.ts
```

Use `.test.ts` or `.test.tsx` for module and component tests. Infrastructure suites live in `infra/tests/` and use `.integration.test.ts`. Playwright suites for the deployed application also live there, with `.browser.test.ts`.

Shared test setup, fixtures, and support code live under `tests/` alongside the suites.

Tests have their own `tests/tsconfig.json`, extending the workspace configuration. This keeps test-runner types out of production code while making each test easy to find from its source path.
